GitHub：\href{https://github.com/tom-cat-mao/TaskWizard-Autoglm}{TaskWizard-Autoglm}
\begin{itemize}
  \item 基于最新 Loop / Harness Engineering 思路，重构成一个连上手机就能实时跟踪、查询任务的 Agent 框架，让任意带视觉能力的 VLM 都能直接操控手机。
  \item Harness 用 LangGraph 串起 plan → execute → reflect 三步，并把感知信息工具化、模块化，重设了 Context Window、做了步骤级的短期记忆，让上下文更干净、模型对状态感知更准。
  \item 模型不直接吐执行命令，而是走中间层把执行过程抽象掉；grounding 走控件树 + 代码实现，模型不输出坐标（坐标对模型又难又易错），另接一个保底 grounding 模型兜住拿不到控件树的情况。
  \item 落了 Loop Engineering 架构，每轮都产出中间产物和真实运行状态，让模型能感知实际跑成什么样；再用 Validator 做最终断言校验，把 phone agent 的地基打实。
\end{itemize}
